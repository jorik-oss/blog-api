# Blog API

Мини-API для блога на Flask и SQLite.

## Технологии

- Python
- Flask
- SQLite

## Эндпоинты

### GET /authors

Получить список всех авторов.

### GET /posts

Получить список всех постов.

### GET /posts/<id>

Получить один пост по ID.

При запросе количество просмотров увеличивается на 1.

### POST /posts

Создать новый пост.

Пример JSON:

`json
{
    "title": "Мой первый пост",
    "content": "Привет, это мой блог",
    "author_id": 1
}
